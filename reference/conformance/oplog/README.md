# Op-log format v1 (PLAN M1.1)

A random history of engine operations, replayed by every implementation's
model checker (M1.2) against the engine **and** a sorted in-memory map. One
JSON object per line, UTF-8, `\n`-terminated. Generated by
`cargo run -p cryptand --features harness --bin oplog_gen -- --seed N`.

## Line 1: header

```json
{"oplog":1,"seed":7,"profile":"desktop","encrypted":false,"trees":2,"keys":1000,"skew":0.5,"big":0.05,"prefix":0}
```

`profile` and `encrypted` say how to create the database; the rest records the
generator knobs so a log can be regenerated. A reader MUST reject `oplog` ≠ 1.

## Encodings

- **key** `"k"`, `"lo"`, `"hi"`: lowercase hex of the raw key bytes. The engine
  key is `Value::Bytes(those bytes)`; the model orders keys by `memcmp` of the
  raw bytes (CKE preserves that order, `spec/03`).
- **value** `"v": {"n": len, "s": seed}` (`seed` < 2⁵³, exact in any JSON parser): `len` bytes taken little-endian from
  successive outputs of SplitMix64 started at `seed` (all arithmetic mod 2⁶⁴):

  ```
  state += 0x9E3779B97F4A7C15
  z = state; z = (z ^ (z >> 30)) * 0xBF58476D1CE4E5B9
  z = (z ^ (z >> 27)) * 0x94D049BB133111EB
  out = z ^ (z >> 31)
  ```
  Random bytes so LZ4 cannot shrink a value below the value-log threshold.
- **tree** `"t"`: tree id, `1..=trees`.

## Ops

| `op` | fields | meaning |
|---|---|---|
| `put` | `t k v [x]` | put; `x` = absolute expiry in ms on the op-log clock |
| `del` | `t k` | point tombstone |
| `range_del` | `t lo hi` | delete `[lo, hi)`; always `lo < hi` |
| `batch` | `ops` | array of `put` (never with `x`) / `del`, committed atomically as one transaction |
| `get` | `t k [at]` | read; compare engine vs model. `at` = snapshot id |
| `scan` | `t [lo] [hi] [at]` | ordered scan of `[lo, hi)`, compare every pair |
| `snapshot` | `id` | take a snapshot, name it `id`; it sees only **committed** writes (`spec/10` §1) |
| `release` | `id` | release it |
| `commit` | `d` | make every write so far committed (Rust: `flush` then `commit`), at durability `none` \| `os` \| `sync` \| `full` |
| `reopen` | | `commit` at `sync`, close, open again; every snapshot was released before |
| `compact` | | full compaction |
| `shrink` | | relocate live extents and truncate |
| `checkpoint` | | `commit` at `full` |
| `ttl_advance` | `ms` | advance the clock; a put with `x ≤ clock` reads as absent |

The clock starts at 0 (Rust `Engine::now_ms`). An absent field means "none"
(unbounded scan side, latest state, no expiry).

At the end of a log, and after every `reopen`, the checker compares a full-scan
digest of every tree: SHA-256 over, in tree order then key order,
`u32be(tree) || u32be(len k) || k || u32be(len v) || v`.
